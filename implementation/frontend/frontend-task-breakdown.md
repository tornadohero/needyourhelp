## 推荐执行顺序

1. **FE-01 → FE-06**（共享基建，两端通用）
2. **FE-10 → FE-22**（管理台 MVP：让平台先可被运营；G1 需先决策，本地可用 bootstrap + mock 推进 UI）
3. **FE-30 → FE-39**（小程序家长主链路，最先产生业务价值，可直接对应 E2E-01）
4. **FE-40 → FE-46**（导师端；**FE-41 需先解决 G3**）
5. **FE-50、FE-51**（消息只读 + 职业赛道；**FE-50 依赖 G4**）
6. **FE-60 → FE-63**（E2E、隐私回归与契约守卫）
